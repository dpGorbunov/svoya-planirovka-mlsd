# EDA

`eda.ipynb` - разведочный анализ данных для ДЗ 2. Собирается из `build_eda.py` (`python build_eda.py eda.ipynb`) и выполняется
`jupyter nbconvert --to notebook --execute --inplace eda.ipynb`. Пути к данным задаются в первой кодовой ячейке:

- `~/svoya-ml/dataset-pik-v3` - картинки планировок ПИК (`images/*.png`) и разметка к ним (`labels/*.json`);
- `data/agent_eval` - сценарии оценки агента правок (git-ignored).

Картинки и разметка в репозиторий не выкладываются. В ноутбуке сохранены выходы ячеек: таблицы, графики, агрегаты и
несколько примеров чертежей. Ноутбук пишет два файла (git-ignored): `data/clean_codes.txt` - коды квартир после фильтра,
`data/split.csv` - деление на обучение, валидацию и тест. Без данных ноутбук не выполняется, читать по сохранённым выходам.
