# Своя планировка - ML System Design

Учебный проект курса "Проектирование систем машинного обучения" (ИТМО, осень 2026).

## О проекте

Своя планировка - сервис для покупателей квартир в новостройках России. Покупатель загружает картинку планировки своей квартиры с сайта застройщика и получает 3D-модель с мебелью, расставленной по нормам эргономики. Расстановку можно менять текстом или вручную, ставить товары по ссылке из магазина и получать список покупок с ценами. По квартире можно пройтись от первого лица в браузере.

На картинке застройщика нет точных размеров. Поэтому планировки заранее оцифровываются в шаблоны по каталогам застройщиков: стены, двери и окна в метрах. Сервис находит шаблон загруженной планировки и строит модель по нему. Если шаблона нет, сервис оцифровывает картинку сам.

ML-части (список может измениться по ходу курса):

| Компонент | Задача |
|---|---|
| Распознавание планировки | Найти шаблон, совпадающий с загруженной картинкой. Если такого нет, сообщить об этом |
| Оцифровка планировки | Если шаблона нет, построить по картинке стены, двери, окна и комнаты в метрах |
| Агент правок | Переставить мебель по текстовой просьбе ("поставь кровать к окну") и проверить, что остались проходы и открываются двери |
| 3D-модель товара | По ссылке на товар Ozon или Яндекс Маркета построить 3D-модель по фото и подогнать её под габариты из карточки |
